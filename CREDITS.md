# Audio credits

These synthetic voices accompany the original learning dialogues in *Everyday Conversations*.
Clear audio was generated with Kokoro-82M v1.0 using kokoro-onnx 0.6.1.
Voice identifiers: am_michael, af_heart, af_bella, am_fenrir.

- Model and its licence: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0)
- Inference software and its licence: https://github.com/thewh1teagle/kokoro-onnx (MIT)

This distribution contains generated audio, not the model weights or inference software.
The model/software licences above identify the tools used and do not assign an open-source
licence to the textbook or its accompanying recordings.
